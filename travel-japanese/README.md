# Japonés de Viaje

Frases útiles en japonés para viajar, con audio, traducción al español, significado de cada palabra y un conversor de números.

Es una PWA: se puede instalar en el teléfono y funciona sin conexión.

## Publicar con GitHub Pages
1. Subí estos archivos a la raíz del repo.
2. En el repo: **Settings → Pages → Build and deployment → Deploy from a branch**, elegí `main` y `/ (root)`.
3. Abrí `https://<usuario>.github.io/<repo>/` en el teléfono.

> GitHub Pages en repos privados requiere un plan pago de GitHub. Con plan gratis, el repo tiene que ser público.

## Instalar en el teléfono
- **iPhone (Safari):** Compartir → «Agregar a pantalla de inicio».
- **Android (Chrome):** menú ⋮ → «Instalar app».

Abrila una vez con internet para que quede guardada para usar offline.

## Audio
Usa la voz japonesa del sistema (Web Speech API). Si no suena, instalá la voz «Japonés» en los ajustes de texto a voz del teléfono.

## Actualizar
Después de cambiar archivos, subí el número de `VERSION` en `sw.js`.
